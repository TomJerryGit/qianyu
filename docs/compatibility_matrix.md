# 真实桌面兼容矩阵

> 本文件用于发布前的真机验收，不是 CI 替代品。每项至少记录一次结果。

## 环境

| 项 | 目标 |
|---|---|
| Windows 10 22H2 | 必测 |
| Windows 11 23H2/24H2 | 必测 |
| 100% DPI | 必测 |
| 125% / 150% DPI | 必测 |
| 200% DPI | 必测 |
| 单屏 1366×768 | 必测 |
| 单屏 1920×1080 | 必测 |
| 4K / 多屏 | 建议 |
| 中文路径 / 长路径 | 必测 |
| 只读媒体目录 | 必测 |
| 睡眠/唤醒 | 必测 |
| 蓝牙/外接音频设备 | 建议 |

## 功能检查

- [ ] 安装 / 卸载干净（无残留进程、无锁文件）
- [ ] 首次启动向导
- [ ] 文件关联双击起播
- [ ] 单实例：再次打开聚焦已有窗口
- [ ] 托盘图标/菜单/关闭到托盘
- [ ] 全局媒体键
- [ ] 本地音乐播放 / 暂停 / 上一首 / 下一首
- [ ] 播放列表拖拽/多选删除
- [ ] 全屏播放页 / 歌词 / 封面
- [ ] 频谱显示 `真实 · FFmpeg` 或 `实时 · 流分析`
- [ ] 电台播放 / 重连 / 收藏
- [ ] 播客搜索/订阅/缓存下载
- [ ] 视频：全屏、退出、字幕/音轨（如有）
- [ ] 远程 Navidrome / Jellyfin 搜索/专辑/串流
- [ ] 睡眠唤醒后音频/UI 不崩溃
- [ ] 切换 DPI/显示器后布局无裁切
- [ ] 中文/英文 UI 无硬编码截断
