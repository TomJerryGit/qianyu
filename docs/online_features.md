# 在线功能设计：参考与路线

目标：在不破坏本地优先、隐私和稳定性的前提下，增加可用的在线能力。

## 参考作品

### 国内

- **千千静听**：在线歌词、专辑封面、歌曲信息补全——本地播放器最经典的在线能力。
- **网易云音乐 / QQ 音乐**：搜索、歌单、推荐、评论、MV、歌词。能力完整，但依赖自有版权服务，不能直接抓取。
- **洛雪音乐 / listen1**：多源聚合搜索。适合参考“聚合”交互，但版权/接口合规风险高，不作为默认实现。

### 国外

- **MusicBee / foobar2000**：网络电台目录、Last.fm、Discogs、歌词、封面补全。
- **Roon / Plex / Jellyfin / Navidrome**：远程媒体库、串流、多设备。
- **Spotify / YouTube Music**：推荐、跨设备、在线歌单。

## 设计原则

1. **公开 API 优先**：Radio Browser、MusicBrainz、LRCLIB、Cover Art Archive。
2. **不抓取付费/版权服务**：不绕过 DRM、不逆向私有接口。
3. **本地优先**：离线仍可播放、管理媒体库。
4. **用户主动触发**：在线请求不后台偷偷上传媒体库。
5. **异步 + 超时 + 缓存**：网络失败不能卡 UI。
6. **可关闭**：设置中允许完全禁用在线功能。

## 已实现（0.9.x）

### 1. 网络电台

- `core/radio.py`：Radio Browser 搜索，按点击量排序，去重/过滤无效 URL。
- `ui/radio_dialog.py`：名称/国家筛选，后台线程搜索，双击播放。
- 主菜单「在线 → 网络电台…」。
- 播放走 libmpv，支持 AAC/MP3/OGG/HLS 等公开流。
- 收藏/最近收听（最近 20 个）、收藏 JSON 导入导出、ICY 当前曲目、断流自动重连。
- 数据来源 Radio Browser；流媒体版权归各电台，详见
  [在线内容与版权合规](online_compliance.md)。

### 2. 打开网络流

- 主菜单「在线 → 打开网络流…」。
- 支持 HTTP/HTTPS 音频/视频流，交给 libmpv。

### 3. 播客

- `core/podcast.py`：iTunes Search API 搜索播客；RSS 解析单集、时长、发布时间。
- `ui/podcast_dialog.py`：搜索播客 → 选择播客 → 加载单集 → 双击/按钮播放。
- 主菜单「在线 → 播客…」。
- 支持 Ximalaya、小宇宙、Anchor 等公开 RSS feed。
- 订阅/取消订阅、我的订阅、已听标记、单集续播记忆。
- 单集下载缓存、下载队列、离线播放、缓存上限（默认 2048 MB，可在设置调整）。

### 4. ListenBrainz Scrobbling（可选）

- 设置中默认关闭；
- 用户 token 只保存在本机配置；
- 仅提交本地音乐，排除网络电台、播客和网络流；
- 播放达到 **50% 或 4 分钟**（取较小值）提交一次；
- 后台线程提交，失败静默，不阻塞播放；
- 提交内容包含曲名、艺术家、专辑、时长、播放器名称。

### 5. 远程媒体库（Subsonic / Navidrome）

- 设置中配置服务器地址、用户名、密码；
- 使用 Subsonic API token（md5(password+salt)）认证，不发送明文密码；
- 远程搜索歌曲并串流播放；
- 兼容 Navidrome、Airsonic、Gonic 等 Subsonic 服务器；
- Jellyfin 使用独立 API，后续单独适配；
- 当前为独立远程搜索面板，本地/远程统一搜索在下一阶段。
- 密码使用 Windows DPAPI 加密后保存在本机配置；API 只发送 Subsonic token。

### 6. 已有在线能力

- MusicBrainz 元数据补全；
- LRCLIB 在线歌词；
- Cover Art Archive 在线封面。

## 下一阶段

### P1 在线电台增强（剩余）

- 按语言/标签浏览；
- 收藏云同步/多设备；
- 电台节目单/回听（仅使用公开 EPG）。

### P2 Last.fm

- Last.fm API key/secret + 用户授权；
- 与 ListenBrainz 共用的播放阈值；
- 默认关闭。

### P3 播放记录同步

- Last.fm / ListenBrainz Scrobbling（需要用户授权/token）；
- 本地播放历史与在线记录去重；
- 默认关闭，明确隐私提示。

### P3 Jellyfin / 统一搜索

- Jellyfin API 适配；
- 本地与远程结果合并搜索；
- 远程播放队列/封面；
- 密码/ token 本地加密存储。

### P5 推荐

- 基于本地播放历史，不依赖云端画像；
- 先做“最近常听/未播放/相似标签”，再做个性化。

## 交互

```
在线
├── 网络电台…
├── 打开网络流…
├── 在线歌词（当前歌曲）
├── 在线封面（当前歌曲）
└── 在线元数据（标签编辑内）
```

所有网络操作：

- 有加载状态；
- 8 秒超时；
- 失败给明确提示；
- 不阻塞主线程；
- 结果可缓存。

## 合规

- 电台流来自公开目录，播放器不存储/转播；
- 不提供盗版音乐搜索/下载；
- 在线服务在隐私政策中披露；
- 用户可完全离线使用。
