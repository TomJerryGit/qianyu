# 在线内容与版权合规

QianYu 是本地优先的播放器。在线功能只使用公开 API、公开 RSS 和公开电台目录，
不抓取受版权保护的流媒体服务，不绕过 DRM，不提供盗版音乐搜索/下载。

## 数据源与条款

| 功能 | 数据源 | 版权/条款要点 |
|---|---|---|
| 网络电台 | Radio Browser | 目录数据由社区维护；电台流版权归各电台/版权方，QianYu 只播放，不录制、不转播、不下载 |
| 播客搜索 | Apple iTunes Search API | 搜索数据由 Apple 提供；使用时保留 “Powered by iTunes” 声明 |
| 播客单集 | 播客发布者 RSS | 音频版权归播客作者；下载仅用于用户个人离线收听，不再分发 |
| 在线歌词 | LRCLIB | 歌词版权归词曲作者/权利方；仅显示给用户个人，不批量抓取、不再分发 |
| 在线封面 | Cover Art Archive | 封面版权归原权利方；仅用于显示/本地缓存，不再分发 |
| 在线元数据 | MusicBrainz | 元数据按其许可使用；保留来源声明 |
| 歌手写真 | Deezer 公共搜索 API | 仅用于当前歌手页面显示/本地缓存，不再分发；版权归原权利方 |
| 远程媒体库 | 用户自建 Subsonic/Jellyfin | 只有用户配置后才连接；不抓取第三方服务 |
| Scrobbling | ListenBrainz | 用户主动开启；token 本地保存；只提交播放记录 |

## 产品约束

1. 不提供音乐搜索、音乐下载、VIP 歌曲、付费曲库破解。
2. 不实现 YouTube/SoundCloud/网易云/QQ 音乐等私有接口抓取。
3. 不绕过 DRM、会员限制、地区限制或反爬。
4. 播客下载只针对 RSS 中公开的 enclosure；下载文件只存在用户本地缓存。
5. 电台只播放公开目录中的流地址，不提供录音/转播功能。
6. 下载/缓存内容不进入安装包、不随 Release 上传、不对外分发。
7. 用户应遵守所在地区法律和来源服务条款；QianYu 不代替用户取得授权。

## 界面声明

- 网络电台窗口：数据来源 Radio Browser；流媒体版权归各电台。
- 播客窗口：数据来源 iTunes Search / RSS；内容版权归原作者。
- 播客下载首次使用：提示仅限个人离线收听。
- 关于窗口：版权、GPL-3.0、数据源和项目地址。

## 第三方软件许可

libmpv/FFmpeg 的具体许可取决于构建。发布二进制前需要：

- 确认 bundled FFmpeg/libmpv 的 LGPL/GPL 状态；
- 随发布提供对应许可证文本；
- 对 GPL 构建提供源码或书面源码获取方式；
- 保留版权声明和修改说明。

详见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。
