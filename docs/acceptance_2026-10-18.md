## 签名

- 已用 Python 生成自签名 PFX（`tools/qianyu-dev-signing.pfx`）；
- `Set-AuthenticodeSignature` 返回 `UnknownError`，副本仍是 `NotSigned`；
- 没有受信任 CA 证书、没有 `signtool`/`osslsigncode`；
- `release.ps1 -RequireSignature` 已验证会拦截未签名产物（当前实测 `Status=NotSigned`，退出 1）；
- **生产 Authenticode 未完成**，自签名也不能解决 SmartScreen 信任。

## 本轮发现的问题

1. **10k 启动 2.25 s、首屏 1.1 s**：可接受但不达“秒开”。
2. **60 秒内存 +14.5 MB**：需长时浸泡确认。
3. **在线封面/歌词不可用**：
   - MusicBrainz 正常；
   - Cover Art Archive 对本机示例 release 返回 404；
   - LRCLIB 超时；
   - 缺少重试、缓存、超时降级。
4. **卸载注册表项未验证**：安装/启动/卸载已通过；本机 HKCU 写入被拒，无法确认“应用和功能”条目；真实桌面需复测。
5. **音频指纹**：PCM 包络回退可用；Chromaprint/fpcalc 未安装，准确率未验。
6. **HDR/HEVC 10-bit**：无硬件。
7. **视频控制条**仍偏拥挤；UI 无高 DPI/无障碍专项。
