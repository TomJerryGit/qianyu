# 视频 1.0 范围冻结：核心 20 项

- **状态**：**已冻结（2026-10-17）**
- **适用范围**：浅语影音 1.0 双模版（音乐 + 视频）
- **原则**：**1.0 只做这 20 项；不在表内的一切视频能力进入 1.2 backlog。** 新增需求必须同时说明“砍掉哪一项”或延后到 1.2，否则不进入 1.0。
- **依据**：[libmpv Spike 报告](../spike/REPORT.md)、[双模播放器路线图](<../浅语影音_双模播放器路线图.md>)
- **机器可读版本**：[`video_scope_1.0.json`](video_scope_1.0.json)
- **实现进度**：[视频模式 MVP 状态](video_mvp_status.md)（V01–V05、V07–V11、V13–V20 已覆盖；V06 字体回退、V12 窗口内覆盖、V17 真实 HDR 部分；V12 全屏手势已用顶层 overlay 验证）

---

## 1. 冻结清单（20 项）

| ID | 功能 | 优先级 | 验收标准（摘要） | 依赖 |
|---|---|---|---|---|
| V01 | 打开本地文件 / 拖放 / 最近 / 命令行 | P0 | 双击、拖入、`--play`、最近列表均能起播；错误有提示 | 文件关联、单实例 |
| V02 | 打开网络 URL（HTTP/HLS） | P0 | 弱网可缓冲/停止；失败可重试；不阻塞 UI | libmpv 网络栈 |
| V03 | 播放/暂停/停止/seek/音量/静音 | P0 | 响应 ≤100 ms；seek 首帧 ≤500 ms | 引擎 |
| V04 | 全屏/无边框/多屏/置顶 | P0 | 切换 ≤200 ms；拖动到不同 DPI 屏不错位 | wid + 窗口控制 |
| V05 | 硬件解码（D3D11VA/DXVA2）+ 软解回退 | P0 | 参考机 4K60 HEVC 0 丢帧；强制软解可播 | 4K/HDR 样片、GPU 矩阵 |
| V06 | 字幕：内嵌/外挂 SRT/ASS/SSA、编码、延迟、字体/大小/位置 | P0 | 简/繁/日/英、GBK/Big5/UTF-8、ASS 特效正确 | libass |
| V07 | 音轨/字幕轨切换 | P0 | 切换无爆音；按文件记忆 | 引擎属性 |
| V08 | 画面比例/裁剪/旋转/去隔行 | P1 | 16:9/4:3/原始/自定义；旋转 90/180/270 | mpv 属性 |
| V09 | 倍速 0.25–4.0（变调补偿） | P1 | 音画同步；无明显失真 | mpv `speed` + pitch |
| V10 | 续播/历史/最近观看 | P0 | ±2 s 恢复；>95% 不提示；异常退出可恢复 | SQLite |
| V11 | 截图（含/不含字幕） | P1 | 路径/格式可配；截图成功 | mpv screenshot |
| V12 | OSD/控制条自动隐藏/滚轮/手势 | P0 | 鼠标/键盘/触控板可用；全屏可退出 | wid + OSC |
| V13 | 视频队列/文件夹连播 | P0 | 播完自动下一集；顺序/随机可配 | 播放列表 |
| V14 | 章节 | P1 | 列表正确；跳转准确 | mpv chapter-list |
| V15 | 书签 | P1 | 增删改；按文件持久化；跳转准确 | SQLite |
| V16 | A-B 循环/逐帧 | P1 | 精确到帧；可清除 | mpv ab-loop/frame-step |
| V17 | HDR→SDR 色调映射 | P1 | HDR10/HLG 不过曝、不发灰；可关闭 | `vo=gpu-next` + HDR 屏 |
| V18 | 字幕样式/位置记忆（按文件） | P1 | 重开恢复字体/大小/位置/延迟 | SQLite |
| V19 | 画面色彩调整（亮度/对比度/饱和度/伽马/色相） | P1 | 实时生效；可重置；按会话记忆 | mpv 属性 |
| V20 | 音频延迟 / A-V 同步调整 | P1 | ±500 ms 可调；音画同步；可重置 | mpv `audio-delay` |

**优先级说明**：

- **P0（10 项）**：1.0 RC 必须全绿；缺一不可发布。
- **P1（10 项）**：1.0 目标全绿；若因硬件/样片阻塞，需产品与技术负责人书面同意后才能降级到 1.0.x，且必须在发布说明中标注。
- 本表不含任何 P2；P2 全部进入 1.2 backlog。

## 2. 1.2 Backlog（明确不在 1.0）

| 能力 | 原因 |
|---|---|
| 双字幕（主/副独立） | 依赖 `secondary-sid` 与 UI，非核心；1.2 |
| seek 缩略图预览 | 需要额外解码管线与缓存；性能风险 |
| SMB / DLNA / DVD / BD | 组件与兼容成本高；1.2 可选组件 |
| 音频直通（AC3/DTS/TrueHD/Atmos） | 家庭影院小众；需功放/驱动矩阵 |
| HDR 直通 / OS HDR | 1.0 只做 HDR→SDR 色调映射；直通需显示器/系统矩阵 |
| render API 自定义覆盖控件 / 视频皮肤 | 1.0 决策为 `wid` + 下方控制条；1.2 评估 OpenGL FBO |
| 3D / VR / 360 | 长尾；不做 |
| 直播流 / 视频采集 | 与播放器定位无关 |
| 视频滤镜/着色器市场 | 生态型能力；1.2+ |
| 在线视频搜索/下载 | 版权与稳定性风险；不做 |
| 视频海报墙/元数据刮削 | 1.0 只做最近/文件夹队列 |
| 画中画（PiP） | 非核心；1.2 |
| 在线字幕搜索/下载 | 需授权与供应商；1.2 |
| 逐帧音频波形/可视化 | 音乐侧 1.3 |

## 3. 范围治理规则

1. **冻结即承诺**：V01–V20 是 1.0 的完整视频范围；产品、设计、开发、QA 共用这一份清单。
2. **新增需求**：只能进 1.2 backlog；若必须进 1.0，必须同时移除一项同等工作量的现有条目，并由产品/技术负责人签字。
3. **每周评审**：只评审“20 项的状态”，不讨论新功能；新想法记录到 backlog，不在会上展开。
4. **验收统一**：每项必须有自动化或可复现的手工用例；P0 项必须有回归测试。
5. **发布门槛**：P0 全绿；P1 缺口需书面豁免；任何未在清单中的视频功能不得出现在 1.0 安装包/宣传中。

## 5. 验收总表（Definition of Done）

每一项完成需同时满足：

- [ ] 功能按验收标准通过（含异常路径）
- [ ] 有自动化测试或可复现手工用例
- [ ] 不引入主线程 >100 ms 阻塞
- [ ] 键盘可操作；中英文文案完整
- [ ] 设置可持久化；坏配置可回退
- [ ] 不崩溃、不泄漏；24h 浸泡通过
- [ ] 文档/帮助已更新
- [ ] 兼容矩阵（Win10/11、DPI、GPU）通过

## 6. 一句话

**1.0 的视频能力 = 这 20 项，一项不多；想要第 21 项，先拿掉一项或等 1.2。**
